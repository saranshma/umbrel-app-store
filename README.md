# Saransh's Umbrel Community App Store

A personal [Umbrel Community App Store](https://umbrel.com/support/apps/how-to-add-a-community-app-store).

Add it in umbrelOS: **App Store → ⋮ → Community App Stores → Add**, then paste this repo's URL.

## Apps

| App | Version | Notes |
|---|---|---|
| [UHF Server](saransh-uhf-server) | 2.0.0 | DVR backend for the [UHF IPTV player](https://getuhf.com). Recordings land on the USB drive at `/home/umbrel/umbrel/external/saransh/uhf-recordings`; the database lives on the internal NVMe. |
